Guide

This guide gives a brief overview of the site, it‘s features and how they can be used.

Finding a chant

The home page lists every chant by category. The category buttons under the search box show one category at a time. The search box searches the titles and the Pali of every chant, and on a category’s page it searches that category only. Long lists continue on further pages, linked at the foot of the list.

Sangha sets, the last category button, lists sequences of chants as a monastery or centre chants them, such as Amaravati Monastery’s morning chanting, under the lineage and the monastery. A set opens as one page that holds its chants in order, each under its own title, so it can be chanted straight through. A set page works like a chant page, in both views and with every way of moving on. Its info panel lists its chants, with links to their own pages.

The chant page

The top bar on each chant page holds (from left to right):

  • a home link back to the chant list;
  • Text and Slides, which switch between two available views;
  • Track (text view only), which marks the current line;
  • Settings, for how the chant is shown and how lines move on;
  • Info, with the chant’s Pali source, available recordings and additional details;
  • the keyboard shortcuts, on devices with a keyboard;
  • the global theme toggle.

The text view

The text view shows the whole chant. With Track on, the current line is marked and kept in view. A click on a line makes it the current line, and the arrow keys move one line at a time. After scrolling away by hand, Back to current line returns to it.

The slide view

The slide view shows a few lines at a time, filling the screen, with the current line marked. It suits chanting from a distance, or from a screen set up in front of a group. On a touch screen, a swipe across a slide moves a line.

The Advance setting chooses how lines move on:

Manual
Lines move on only when asked: with the next and previous buttons, the arrow keys, Space or a swipe.
Auto
Lines move on at a pace worked out from the Pali, so longer lines are given more time. The speed slider in the settings, from tortoise to hare, sets the pace, and the + and − keys change it while chanting.
Timed
Lines move on by a timing file, which gives the time each line starts. A chant with a timing taken from a recording uses it by default. Other chants start with a timing worked out from the Pali, as with Auto.

With Auto or Timed, Start sets the lines moving and Pause stops them.

Chanting with a recording

Under Audio in the settings, Add audio file chooses an audio file from the device, such as a monastery’s recording of the chant. The chant’s info panel lists the recordings that have a timing file, with links to where they can be found. MP3 and AAC files play in all current browsers and other file types, such as OGG, have variable support.

Once a file is added, its controls appear at the foot of the page: back, play or pause, forward and stop. A press on back or forward moves 3 seconds, and holding it rewinds or fast-forwards.

In the slide view with Auto or Timed advance, the lock at the start of the bottom bar locks the audio to the slides. It is closed while the audio is locked, and a press opens or closes it:

  • With Timed advance and a timing from the same recording, the lines follow the audio. Start, Pause and moving a line act on the audio as well.
  • With Auto advance, or Timed advance with a timing worked out from the Pali, Start and Pause also play and pause the audio.
  • With the lock open, the audio and the slides run separately.

The file is remembered for that chant, or that set, on this device. Chrome and Edge keep only a link to the file and ask for permission to read it again on a later visit. Other browsers keep a copy of the file.

Timing files

With Timed advance, the settings name the timing in use and offer three actions:

Use default
Returns to the default timing of the chant or set.
Import timing
Loads an LRC file, for example one edited by hand to match a different recording.
Export timing
Saves the timing as an LRC file, the plain text format used for the timed lyrics of songs. Each row gives a time and a line. On a set page, the file has a block of rows for each chant.

Display settings

The settings also define the text size of each view, whether the English translation is shown, and, for chants that have them, the men’s or women’s forms of the words. These settings apply to every chant.

Privacy

The site has no accounts, no cookies, no analytics and no usage tracking. Its pages, fonts and scripts are all served from the site itself, so nothing is loaded from other websites.

Settings, the current line of each chant and imported timing files are kept in the browser’s storage on this device. So is a chosen audio file, as a link or a copy (see Chanting with a recording). None of this is sent anywhere, and audio files are never uploaded. Clearing the site’s data in the browser removes all of it, and Remove under Audio in the settings forgets the audio file of one chant or set.

The site is hosted by Netlify. As with any website, the browser sends Netlify’s servers the details of each request, such as its IP address and browser type. How Netlify handles them is set out in its privacy policy.
